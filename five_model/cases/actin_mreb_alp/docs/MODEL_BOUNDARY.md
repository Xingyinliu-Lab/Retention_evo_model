# MreB/ALP composition-corrected five-model boundary

States are defined from the frozen aggregate table: M-only contains `MreB/Mbl-like`, `MreB-like` and `C/ALP-N-related`; ALP-only contains cALP or dALP; coexistence contains both aggregates in the same MAG.

Five models are compared on identical tips within each species tree. ARD and all three reversible adjacency graphs use the stationary distribution of their fitted Q matrix as the root prior. The strict ancestral-coexistence model alone fixes the root to coexistence. Mirrored verbal directions of a reversible adjacency graph are not separate models.

The primary comparison uses unit topology, matching the former GTDB-only figure and avoiding interpretation of heterogeneous, partly absent and non-clock branch lengths. Delta AIC is calculated separately within each tree. Absolute likelihoods are not compared across trees. The six trees are sensitivity reconstructions, not independent biological replicates.

This analysis tests host-state transition structure. It does not identify duplication, transfer or loss events, infer M-to-ALP direction, or establish that MreB and ALP form one homologous gene family.
