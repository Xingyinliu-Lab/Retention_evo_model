# Actin dALP/cALP five-model case

This is the final composition-corrected six-species-tree analysis. `input/` contains the frozen tree/state inputs and source tables; `output/` contains the five-model fits and paired summaries; `run/` contains the original Windows and Linux entry points.

`ARD_transition_contribution/` contains the final composition-corrected ARD decomposition code and outputs, including coexist-mediated and direct-endpoint posterior transition contributions.

State direction is not inferred from the unrooted gene tree. Sequential Retention means that coexistence is the required intermediate state, not that either endpoint is fixed as ancestral.
